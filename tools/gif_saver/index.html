GIF Saver

8-bit GIFs → the knob's 428 × 142 screen

1Import

Paste a link to a GIF (or to its Giphy/Tenor page), or drop / paste an image file anywhere on the page.

2Pixels

Find the size of one "8-bit" pixel in the image, so each one becomes a single pixel again. Auto-detect usually gets it; check the grid lines sit on the pixel borders and compare Source and Result (hold the mouse on the image to flip).

3Screen

Each art pixel is shown as a square of screen pixels. Drag the frame (or click where it should go) to pick the part that ends up on the screen; scroll over it to change the scale.

4Preview & export

The screen GIF is exactly what the panel shows. The art-pixel GIF is the same cut at one pixel per art pixel (the scale goes in its name): far smaller, and it gets drawn scaled up.
