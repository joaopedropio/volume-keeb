Screen

What the knob shows while you aren't using it. Turning or pressing the knob brings the controls back; that first touch does nothing else. Make your own from GIFs on the GIF page.

Fonts

Upload any TrueType or OpenType font. It's resized to fit each spot on the screen, converted on this computer and stored in the knob's flash, so it stays after a reboot. Characters outside basic ASCII (accents and so on) show as their plain letters.

Updates

New versions come out on GitHub. This app asks GitHub for the latest one every few hours, unless you turn that off below; nothing about you or your computer is sent.
